# Security policy

## Reporting a vulnerability
Please do not open a public issue for a security problem. Report it privately on GitHub: the
**Security** tab, then **Report a vulnerability**. Include what you found, how to reproduce it, and
the commit it applies to.

The maintainer aims to answer within 7 days. A fix is published as soon as it is ready, and the
report is credited unless you ask otherwise.

## Scope
Potakt is pre-release (Phase 0, a validation experiment). The latest commit on `main` is in scope.
API keys are never stored in the repository; if you find one, report it as above.
